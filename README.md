Projetos selecionados por permitirem consultar o código, compreender o escopo dos exercícios e examinar as decisões de implementação.

**Evidências para explorar:** estrutura do código, contratos dos endpoints e escolhas de organização da aplicação.

**Evidências para explorar:** lógica de interação, implementação da interface e materiais de aprendizagem.

Utilizo projetos práticos para investigar conceitos de software e compreender o comportamento das soluções. Durante o desenvolvimento, reviso implementações, executo testes compatíveis com cada exercício e registro limitações e aprendizados.
